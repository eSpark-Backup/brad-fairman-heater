## Configurations of Board Parameters

1. These macros are define in app.h file.
    - TEMPERATURE_THRESHOLD_VIB_MOTOR for setting the threshold temperature at which the vibration motor should start
    - TEMPERATURE_HEATER_LOW_THRESHOLD Below this temperature the heater should start
    - TEMPERATURE_HEATER_HIGH_THRESHOLD 70.0f Exceeding this temperature the heater should stop.
